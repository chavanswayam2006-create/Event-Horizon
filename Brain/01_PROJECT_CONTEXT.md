# 01 - Project Context

- **Project Name**: Event Horizon
- **Problem Statement**: "The RTI Black Hole" (Problem Statement No. CX0107)
- **Domain**: Artificial Intelligence and Machine Learning
- **Team**: Tensor Float
- **Event**: MUSA CodeX 2026 Hackathon

## The Problem
Right to Information (RTI) applications in India frequently get lost, delayed, or rejected because citizens file them with the wrong government department. Different municipal corporations, state departments, and parastatals have overlapping or non-obvious boundaries of responsibility.

## Core Solution
Event Horizon is an AI-assisted routing system that analyzes RTI application text, identifies the relevant government department, and critically says **"I don't know" (UNKNOWN)** or **"AMBIGUOUS"** instead of guessing when it is genuinely unsure or when jurisdiction is shared across multiple bodies.

## Central Product Principle
**Safety over hallucination.** A wrong routing wastes months of citizen time; refusing to guess and asking for clarification or flagging shared jurisdiction is strictly superior to a confident false positive.
