# Event Horizon Brain - Knowledge Base

## Overview
This `Brain/` directory serves as the structured knowledge and memory layer for Event Horizon. It stores verified project requirements, architecture, API contracts, schemas, decision engine rules, and testing standards to allow AI agents and developers to work efficiently without hallucinations.

## Authority Model
1. **Running / Implemented Source Code** (`backend/`, `frontend/`, `data/`)
2. **Automated Tests** (`backend/tests/test_acceptance.py`)
3. **Current Schemas & Contracts** (`Brain/05_DATA_SCHEMA.md`, `Brain/09_API_CONTRACTS.md`)
4. **Current Documentation & Brain Summaries**
5. **Historical Planning Notes**

## File Guide
- `01_PROJECT_CONTEXT.md`: Team, problem statement, core purpose.
- `02_PRODUCT_REQUIREMENTS.md`: User journeys and functional requirements.
- `03_MVP_SCOPE.md`: Strict boundaries for Day 1 vs future roadmap.
- `04_ARCHITECTURE.md`: Pipeline architecture and module topology.
- `05_DATA_SCHEMA.md`: Star Map JSON & API payload specifications.
- `06_AI_BEHAVIOR.md`: Keyword extraction & TF-IDF similarity mechanics.
- `07_DECISION_ENGINE.md`: Escape Velocity Engine thresholds (CLEAR, AMBIGUOUS, UNKNOWN).
- `08_STAR_MAP_KNOWLEDGE.md`: Demonstration dataset notes & districts.
- `09_API_CONTRACTS.md`: FastAPI endpoints (`/api/analyze`, `/api/starmap`, `/api/health`).
- `10_UI_UX_REQUIREMENTS.md`: Frontend layout and color-coded status badges.
- `11_DEMO_SCENARIOS.md`: The 3 core acceptance test cases.
- `12_TESTING_KNOWLEDGE.md`: Verification commands and test suites.
- `13_TECH_STACK.md`: Installed technologies and runtimes.
- `14_REPOSITORY_MAP.md`: File tree mapping.
- `15_DECISIONS.md`: Architectural Decision Records (ADRs).
- `16_KNOWN_LIMITATIONS.md`: Boundaries of demonstration datasets and heuristics.
- `17_KNOWN_ISSUES.md`: Tracked bug log.
- `18_CHANGELOG.md`: Significant implementation milestones.
- `19_AGENT_RULES.md`: Mandatory behavior guidelines for AI assistants.
- `source_registry.md`: Provenance mapping for critical project facts.
